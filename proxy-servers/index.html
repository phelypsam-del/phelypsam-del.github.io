Python Proxy Servers

Run your own

Two dependency-free forward proxies written with Python's asyncio. Requires Python 3.8+.

Download http_proxy.py Download socks5_proxy.py

HTTP / HTTPS proxy

Forwards HTTP requests and tunnels HTTPS (CONNECT) without decrypting it. Optional Basic auth and allow/block lists. Default port 8080.

python3 http_proxy.py --port 8080 --auth user:pass
curl -x http://user:pass@127.0.0.1:8080 https://example.com

SOCKS5 proxy

TCP CONNECT with IPv4, IPv6 and domain targets. Optional username/password auth. Default port 1080.

python3 socks5_proxy.py --port 1080 --auth user:pass
curl --socks5-hostname user:pass@127.0.0.1:1080 https://example.com

Options

--host bind address (default 127.0.0.1; use 0.0.0.0 for remote clients and always set --auth) · --port · --auth user:pass · --block / --allow (HTTP proxy only)
